# LeetCode Map

A Chrome extension that shows LeetCode problems similar to the one you're on: easier ones to warm up with on the left, harder ones to level up with on the right.

Install: [Chrome Web Store](https://chromewebstore.google.com/detail/leetcode-map/hbponnlnmcomlbplhcbhfaeckbnngdim)

## Report a bug or request a feature

Open an issue and include:

- the problem you were on (number or link)
- what you expected and what happened
- a screenshot of the popup, if you can

You can also email shashank.swe.2020@gmail.com.

## Privacy
